ChatGPT Session 工具

粘贴一次 Session，即可转登录态 Cookie、查询订阅、取消自动续费。凭证只在你本机使用。

Session JSON

登录 chatgpt.com 后打开 https://chatgpt.com/api/auth/session，把整段返回的 JSON 粘到这里。

① 转登录态 Cookie（Cookie-Editor 格式）

把 sessionToken 转成 __Secure-next-auth.session-token，可在浏览器 Cookie-Editor 里「Import」直接恢复登录态。

② 查询订阅 / 取消自动续费

查询套餐、到期日、续费状态、来源平台；再一键打开官方订阅管理页取消续费（权益保留到到期日，到期后不再扣款）。

说明：Session 等同临时登录钥匙，用完可在 ChatGPT「退出所有设备」收回。异地/自动化操作账号有触发风控的风险。
